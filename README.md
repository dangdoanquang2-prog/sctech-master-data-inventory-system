# 01 — SCTECH Relational Master Data & Inventory Control System (Excel/VBA)

## Overview
Engineered by **Doan Quang Dang** (Founder & Curriculum Lead at [SCTECH](https://sctech.vn)), this repository contains:
1. **Inventory_Master_System.xlsx**: A 9-sheet relational Master Data & Inventory Control workbook (MasterData, Inbound_Log, Outbound_Log, FIFO_Tracking, Báo_Cáo_Nhập, Báo_Cáo_Xuất, ABC_Analysis, Inventory_Mgt) built with Dynamic Excel Tables (	bl_Inbound, 	bl_Outbound, 	bl_FIFO, 	bl_ABC) and Name Manager validation lists (lst_SKU, lst_Customer, lst_Lot).
2. **DA-Modules/ (Modules 1–8)**: Practical hands-on workbooks for the **SCTECH 8-Module Supply Chain Data Analytics & Master Data Cleaning Course**, covering text normalization (TRIM, PROPER), cross-table reconciliation (VLOOKUP, INDEX/MATCH, SUMIFS), Pareto 80/20 ABC analysis, EOQ/EPQ optimization, stochastic (Q, R) / (R, S) safety stock, and Executive Pivot/Slicer Dashboards.
